# Forklore

Pantry, recipe, and calorie tracking — solo or shared with your household.

Vite + React + TypeScript SPA, themed with MUI v6 and installable as a PWA. See `docs/` for the schema, RPCs, frontend architecture, routes, and design system specs driving implementation.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
